# 🚗 Traffic Detect System (交通流量实时监控系统)

基于 YOLOv8 与 PyQt5 构建的现代化交通流量检测与计数系统。

## ✨ 核心功能

* **多源输入**：支持本地视频文件 (.mp4, .avi 等) 以及实时摄像头画面。
* **智能识别**：基于 YOLOv8 模型，精准识别并区分 Car (小汽车)、Motorcycle (摩托车)、Bus (公交车) 和 Truck (卡车)。
* **动态画线计数**：支持在视频画面中通过鼠标左键动态绘制/修改检测线，右键清除检测线。车辆跨越检测线时自动增加计数。
* **现代 UI 界面**：自适应窗口缩放，实时分类展示统计数据。

## 📂 项目目录结构与包说明

本项目将不同职责的代码严格划分到了单独的文件夹（包）中：

```text
CarDet/
 │
 ├── main.py             # 🚀 项目主入口 (Controller)
 │
 ├── core/               # 🧠 核心算法包 (Model)
 │    ├── __init__.py    
 │    └── detector.py    # YOLOv8 视觉引擎：负责目标检测、ByteTrack 追踪、画线与过线数学逻辑计算
 │
 ├── ui/                 # 🎨 用户界面包 (View)
 │    ├── __init__.py    
 │    └── layout.py      # 界面布局：基于 PyQt5 构建的窗口、按钮、标签、视频播放区等静态 UI 组件
 │
 ├── config/             # ⚙️ 统一配置包
 │    └── __init__.py    # 静态变量中心：存放车辆类别字典 (VEHICLE_CLASSES) 与界面美化样式表 (STYLE_SHEET)
 │
 └── weight/             # 📦 模型权重库
      └── yolov8n.pt     # YOLO 官方预训练权重文件 (支持自行替换为训练好的定制权重)

```

### 🧩 模块详细说明

* **main.py (控制器)**
整个程序的唯一入口。它负责将 ui (界面) 和 core (算法) 粘合在一起。它处理用户的鼠标点击事件、按钮交互、控制摄像头的启停，并将从 core 拿到的图像和数据刷新到 ui 界面上。
* **core (AI 核心)**
完全独立于界面的“黑盒”。它不关心界面长什么样，只负责接收 main.py 传来的每一帧图像，利用 YOLOv8 进行推理，并返回画好检测框的图像和统计数据。
* **ui (界面表现)**
纯粹的排版文件。定义了视频显示在左侧，超大按钮呈 2x2 网格排列在下方，以及右侧的数据统计面板。
* **config (配置)**
将分散在代码各处的“魔法数字”（如分类 ID）和一大串 CSS 样式代码集中管理，保证业务代码的整洁。
* **weight (模型文件)**
专门用于存放 .pt 后缀的模型权重文件，避免主目录杂乱。

## 🛠️ 快速开始

### 1. 环境依赖

请确保你的 Python 环境中安装了以下核心依赖：

* PyQt5 (或 PySide6)
* opencv-python
* ultralytics (YOLOv8)
* torch

执行以下命令：
```bash
py -3.10 -m venv venv310
venv310\Scripts\activate
python -m pip install --upgrade pip
pip install lap ultralytics opencv-python PyQt5
```
### 2. 运行项目

激活你的虚拟环境（例如 venv310），在项目根目录（CarDet）下执行以下命令即可启动系统：

```bash
python main.py

```

### 3. 操作说明

1. 点击 **Open Video** 选择本地视频，或点击 **Camera** 打开摄像头。
2. 点击 **Start** 开始检测。
3. 在左侧视频画面中，**按住鼠标左键并拖动**即可绘制一条虚拟检测线。
4. 在视频画面中点击**鼠标右键**可清除当前检测线。
5. 右侧面板会实时刷新各类车辆的出现总数及跨线数量。
